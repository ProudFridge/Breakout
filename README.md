# Breakout
This project is a breakout clone with some additional features, where the player's goal is to beat all the levels.

### Features
- Custom Levels:The game has support for custom levels, simply clone the repo, edit the levels.json file, and launch the project in Godot
- Ability System: Each block has the change to carry an ability that activates when the block is destroyed
- Different difficulties: There's three different diffculties, with each one modifying the health of each block and the chance of abiltiies spawning

### How to run
1. Download and unzip  the binaries from the github release page or play the web version on itch.

### How to play
-`Q/E`: Tilt the paddle left/right
- Destroy all the blocks in the scene, without letting the white ball touch the bottom.

### Assets used
- [FreeSFX](https://kronbits.itch.io/freesfx) for the ability sound effects
- [Universal UI/Menu Soundpack](https://cyrex-studios.itch.io/universal-ui-soundpack) for the ui

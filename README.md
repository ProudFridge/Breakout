# Breakout
A breakout clone with some additional features.
Try and beat all the levels :)

### How to run
1. Download the binaries from the github release page or play the web version on itch.

### How to play
-`Q/E`: Tilt the paddle left/right
- Destroy all the blocks in the scene, without letting the white touch the bottom.

### Assets used
- [FreeSFX](https://kronbits.itch.io/freesfx) for the ability sound effects
- [Universal UI/Menu Soundpack](https://cyrex-studios.itch.io/universal-ui-soundpack) for the ui
